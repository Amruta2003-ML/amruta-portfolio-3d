## 🛠️ Tech Stack

- **3D Graphics Engine**: Three.js (WebGL, ACESFilmicToneMapping, dynamic lighting, procedural geometry)
- **Animation & Physics**: GSAP (GreenSock Animation Platform) Bezier flight curves & camera choreography
- **Audio Synthesizer**: Web Audio API (zero external audio files needed; ambient space drone, supersonic whoosh, landing chimes)
- **UI & FX**: Glassmorphism CSS with backdrop-filter, Canvas Confetti
- **Build Tool**: Vite 5

## 🏃 Quick Start Guide

### 1. Run Locally
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 2. Build for Production
```bash
npm run build
```
Creates an optimized static bundle in `dist/`.

### 3. Deploy in 1-Click
- **Vercel**: Run `npx vercel` or push to GitHub and import repository.
- **GitHub Pages**: Deploy the `dist` folder via `gh-pages` or GitHub Actions.
- **Netlify**: Drag and drop the `dist` folder into Netlify Drop.
